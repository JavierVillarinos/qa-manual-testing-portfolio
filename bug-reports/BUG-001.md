# BUG-001: Las imágenes no corresponden a los productos

**Aplicación:** SauceDemo

**Usuario de prueba:** `problem_user`

**Tipo:** Defecto visual / funcional

**Precondiciones:** Iniciar sesión correctamente con el usuario de prueba.

**Pasos para reproducir:**

1. Iniciar sesión en SauceDemo.
2. Acceder al catálogo de productos.
3. Comparar las imágenes mostradas con los nombres de los productos.

**Resultado esperado:** Cada producto debe mostrar una imagen que corresponda al producto indicado.

**Resultado obtenido:** Se observan imágenes que no corresponden a los productos mostrados.
