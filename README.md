QA Manual Testing Portfolio
Sobre el proyecto

Este repositorio contiene prácticas de QA Manual Testing orientadas al diseño, documentación y ejecución de casos de prueba para funcionalidades de aplicaciones web.

Objetivos
Practicar el diseño y la documentación de casos de prueba.
Validar escenarios positivos y negativos.
Identificar errores y documentar resultados.
Desarrollar habilidades fundamentales para un puesto Junior QA Tester.
Contenido
Test Cases: documentación de casos de prueba.
Bug Reports: registro y documentación de defectos.
Test Results: resultados de ejecución de pruebas.
